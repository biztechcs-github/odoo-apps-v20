One-time setup

Full control from a single settings page

Everything lives under Default Report Settings on your company. Choose the default invoice template, report logo, base and background colours, company and customer name colours, report font and font size, footer style, watermark, product images and amount in words. Set it once and every invoice follows.

Per customer

A different template for every customer

Open any contact, go to Report Configuration and pick the invoice template that suits them. That choice overrides the company default, so each customer always receives the layout you chose for them.

Payment clarity

Show payments right on the invoice

Print the payment terms, the payment status and a clear breakdown of untaxed amount, taxes and total, with the amount in words underneath. Payment terms and payment descriptions can be switched on or off, so customers see exactly what is still outstanding.

Brand protection

Watermark your invoices

Give every document a professional touch. Print your own text, the document status or your company logo as a subtle watermark, with full control over the watermark text, its font size and its colour.

Before you install

Python dependencies

Install these libraries on your server. Use wkhtmltopdf 0.12.x (with patched Qt) for the best rendering.

img2pdf

sudo apt-get install python3-img2pdf
OR
sudo pip3 install img2pdf

fpdf

sudo apt-get install python3-fpdf
OR
sudo pip3 install fpdf

num2words

sudo apt-get install python3-num2words
OR
sudo pip3 install num2words
